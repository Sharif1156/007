# ⚡ DESCO Energy Agent

DESCO Prepaid কাস্টমার পোর্টাল (https://prepaid.desco.org.bd) থেকে রিয়াল-টাইম মিটার ব্যালেন্স, রিচার্জ এবং বিদ্যুতের খরচের তথ্য দেখার জন্য একটি AI এজেন্ট ও ড্যাশবোর্ড 앱।

## এটা কী করে

- **মিটার ব্যালেন্স দেখা** — বর্তমান ব্যালেন্স (৳) এবং বাকি ইউনিট
- **খরচের গ্রাফ** — গত ৩০ দিনের দৈনিক খরচ ও আজকের utilizó pattern
- **রিচার্জ ইতিহাস** — कबা কবে কত টাকা রিচার্জ করা হয়েছে
- **রিচার্জ করা** — ডেমো মোডে টেস্ট রিচার্জ (যেকোনো অপরিম পরিমাণে)
- **AI এজেন্ট পরামর্শ** — ব্যবহার 분석 করে সাশ্রয়ের টিপস এবং সতর্কতা (যেমন: আজ ব্যবহার গড়ের চেয়ে বেশি)

## রান কর bestehenden

১. রেপোতে যান:

```bash
cd desco-energy-agent
```

২. ডিপেন্ডেন্সি ইন্সটল করুন:

```bash
npm install
```

৩. `.env` ফাইল তৈরি করুন:

```bash
cp .env.example .env
```

ডিফল্টে `DEMO_MODE=true` রাখুন — এতে কোনো DESCO লগইন ছাড়াই অ্যাপ চালু হবে এবং সিমুলেটেড ডাটা দেখাবে।

৪. সার্ভার চালু করুন:

```bash
npm start
```

পświad গিয়ে খুলুন: **http://localhost:3000**

লগইন স্ক্রিনে যেকোনো কনজুমার নম্বর ও পাসওয়ার্ড দিয়ে লগইন করুন (ডেমো মোডে সব কিছু работает)。

## রিয়াল DESCO API সংযুক্ত করতে

এই স্যান্ডবক্স থেকে https://prepaid.desco.org.bd সাইটে সরাসরি প্রবেশ করা যায় না, তাই সার্ভারের ভেতর এন্ডপಾಯেন্ট URL গুলো প্লেসহোল্ডার রাখা হয়েছে। রিয়াল পোর্টাল সংযুক্ত করতে:

১. আপনার ব্রাউজারে DESCO Prepaid পোর্টাল খুলুন (লগইন করে)।
২. DevTools খুলুন → **Network** ট্যাব।
৩. লগইন, ব্যালেন্স, খরচ, রিচার্জ পেজগুলো ভিজিট করুন এবং রিকোয়েস্টের URL গুলো নোট করুন (যেমন: `/api/meter-balance`, `/api/consumption` ইত্যাদি)।
৪. `.env` ফাইলে `DEMO_MODE=false` করুন এবং URL গুলো বসান:

```
DEMO_MODE=false
DESCO_BASE_URL=https://prepaid.desco.org.bd
REAL_LOGIN_ENDPOINT=/api/...   # আপনার পাওয়া রিয়াল URL
REAL_BALANCE_ENDPOINT=/api/...
REAL_CONSUMPTION_ENDPOINT=/api/...
REAL_RECHARGE_ENDPOINT=/api/...
REAL_HISTORY_ENDPOINT=/api/...
```

৫. `server.js`-এ 있는 `DESCOApiClient` ক্লাসে রিকোয়েস্ট বডি ফরম্যাট রিয়াল API অনুযায়ী সেট করুন (প্র(payload), হেডার, টোকেন নাম ইত্যাদি)।

## স্ক্রিনশট / ডেমো

র্যান্ডমলি ডাটা জেনারেট হয়: কাস্টমার মোঃ রাহিম উদ্দিন, কনজুমার নম্বর `DESCO-2024-8841`, মিটার `M-8841-92`। রিচার্জ করলে ব্যালেন্স ও ইউনিট লাইভ আপডেট হবে এবং AI প্যানেলে পরামর্শ আসবে।
